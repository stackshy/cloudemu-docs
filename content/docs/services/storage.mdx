Store and retrieve objects entirely in memory. cloudemu implements the **object storage** API of all three clouds — creating buckets and containers, putting and getting objects, listing them by prefix, and copying them around. The exact SDK code you'd write against real AWS, Azure, or GCP runs against a local server instead: nothing touches a real bucket, nothing is billed, and every call returns in milliseconds.

| Provider | Real service | cloudemu driver |
|---|---|---|
| **AWS** | S3 — buckets + objects | `aws.S3` |
| **Azure** | Blob Storage — containers + blobs | `azure.BlobStorage` |
| **GCP** | Cloud Storage (GCS) — buckets + objects | `gcp.GCS` |

There are two ways to drive it, both backed by the same in-memory state:

- **Real cloud SDK** — point your existing `aws-sdk-go-v2`, `azure-sdk-for-go`, or `cloud.google.com/go` client at a local server. Only the endpoint changes; your production code is untouched. This is the closest thing to testing against the real cloud, and what most tests should use.
- **Portable Go API** — call cloudemu's Go interface directly and skip the HTTP hop. The same method shape works across every cloud, so you can switch providers by changing one field.

## Drive it with the real SDK

cloudemu ships an HTTP server per cloud that speaks that provider's real wire protocol. You start it with `httptest`, hand it the drivers you need, and point your normal SDK client at its URL — nothing else in your code changes.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

```go
import (
    "github.com/aws/aws-sdk-go-v2/aws"
    "github.com/aws/aws-sdk-go-v2/service/s3"
    awsserver "github.com/stackshy/cloudemu/server/aws"
)

cloud := cloudemu.NewAWS()
ts := httptest.NewServer(awsserver.New(awsserver.Drivers{S3: cloud.S3}))

client := s3.NewFromConfig(cfg, func(o *s3.Options) {
    o.BaseEndpoint = aws.String(ts.URL) // the only change from real AWS
    o.UsePathStyle = true
})

client.CreateBucket(ctx, &s3.CreateBucketInput{Bucket: aws.String("my-bucket")})
client.PutObject(ctx, &s3.PutObjectInput{
    Bucket: aws.String("my-bucket"),
    Key:    aws.String("config.yaml"),
    Body:   bytes.NewReader([]byte("port: 8080")),
})
out, _ := client.GetObject(ctx, &s3.GetObjectInput{
    Bucket: aws.String("my-bucket"), Key: aws.String("config.yaml"),
})
```

```go
import (
    "github.com/Azure/azure-sdk-for-go/sdk/storage/azblob"
    azureserver "github.com/stackshy/cloudemu/server/azure"
)

cloud := cloudemu.NewAzure()
ts := httptest.NewTLSServer(azureserver.New(azureserver.Drivers{
    BlobStorage: cloud.BlobStorage,
}))

// Point the real azblob client at ts (service URL + ts.Client()).
client, _ := azblob.NewClientWithNoCredential(ts.URL, optsFor(ts))

client.CreateContainer(ctx, "my-container", nil)
client.UploadBuffer(ctx, "my-container", "config.yaml", []byte("port: 8080"), nil)
```

```go
import (
    "cloud.google.com/go/storage"
    gcpserver "github.com/stackshy/cloudemu/server/gcp"
)

cloud := cloudemu.NewGCP()
ts := httptest.NewServer(gcpserver.New(gcpserver.Drivers{Storage: cloud.GCS}))

client, _ := storage.NewClient(ctx,
    option.WithEndpoint(ts.URL), // the only change from real GCP
    option.WithoutAuthentication(),
    option.WithHTTPClient(ts.Client()),
)

w := client.Bucket("my-bucket").Object("config.yaml").NewWriter(ctx)
w.Write([]byte("port: 8080"))
w.Close()
```

## What each provider supports

Not every provider names these operations the same way — cloudemu matches what each cloud's own API offers.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

**S3** — `CreateBucket`, `DeleteBucket`, and `ListBuckets` for the container side; `PutObject`, `GetObject`, `HeadObject`, and `DeleteObject` for the objects. `ListObjectsV2` supports `prefix`, `delimiter`, common prefixes, and continuation tokens, and `CopyObject` duplicates an object server-side.

</Tab>

<Tab value="Azure">

**Blob Storage** — the same shape over the data plane: create, delete, and list **containers**, plus `PutBlob`, `GetBlob`, and `DeleteBlob` on the blobs inside them, with `CopyBlob` for server-side copies.

</Tab>

<Tab value="GCP">

**Cloud Storage** — create, get, list, and delete **buckets**, plus upload, download, copy, and delete for the **objects** within them, mirroring the GCS JSON API.

</Tab>

</Tabs>

## How the emulator behaves

cloudemu reproduces the parts of object storage that tests actually lean on, not just a flat key-value dump:

- **Prefix and delimiter listing work like the real thing.** `ListObjectsV2` honors `prefix`, `delimiter`, common prefixes, and continuation tokens, so pagination-aware code pages through results exactly as it would against real S3.
- **Copies are server-side.** `CopyObject` / `CopyBlob` duplicate an object's bytes and metadata in place without a round trip through your process.
- **A couple of extras are driver-only.** Bucket lifecycle policies are exposed on the Portable Go API but not yet on the SDK-compat HTTP server. Everything else — including multipart upload and versioning — works over both surfaces.

## Or call the Portable Go API directly

When you don't need the HTTP layer — for example, unit tests that construct cloudemu in-process — call its Go interface directly. The method shape is identical across clouds, so switching providers is a one-line change.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

```go
aws.S3.CreateBucket(ctx, "my-bucket")
aws.S3.PutObject(ctx, "my-bucket", "config.yaml", []byte("port: 8080"), "text/yaml", nil)
obj, _ := aws.S3.GetObject(ctx, "my-bucket", "config.yaml")
```

</Tab>

```go
azure.BlobStorage.CreateBucket(ctx, "my-container")
azure.BlobStorage.PutObject(ctx, "my-container", "config.yaml", []byte("port: 8080"), "text/yaml", nil)
obj, _ := azure.BlobStorage.GetObject(ctx, "my-container", "config.yaml")
```
