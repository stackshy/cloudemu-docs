---
title: Container Registry
description: Emulate ECR, Azure Container Registry, and Artifact Registry — repositories, images, lifecycle policies, and scans, all in memory.
---

Store and manage container images entirely in memory. cloudemu emulates the **registry control plane** of all three clouds — creating repositories, pushing and listing image manifests, tagging, and the lifecycle and vulnerability-scan machinery around them. No registry is stood up, no layers are uploaded, and every call returns in milliseconds, so tests that depend on a repository or an image can set one up without touching a real registry.

| Provider | Real service | cloudemu driver |
|---|---|---|
| **AWS** | Elastic Container Registry (ECR) | `aws.ECR` |
| **Azure** | Azure Container Registry (ACR) | `azure.ACR` |
| **GCP** | Artifact Registry | `gcp.ArtifactRegistry` |

There are two ways to drive it, both backed by the same in-memory state:

- **Real cloud SDK** — point your existing `aws-sdk-go-v2`, `azure-sdk-for-go`, or `google.golang.org/api` client at a local server. Only the endpoint changes; your production code is untouched. This is the closest thing to testing against the real cloud, and what most tests should use.
- **Portable Go API** — call cloudemu's Go interface directly and skip the HTTP hop. The same method shape works across every cloud, so you can switch providers by changing one field.

## Drive it with the real SDK

cloudemu ships an HTTP server per cloud that speaks that provider's real registry wire protocol. You start it with `httptest`, hand it the drivers you need, and point your normal SDK client at its URL — nothing else in your code changes.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

```go
import (
    "github.com/aws/aws-sdk-go-v2/aws"
    awsecr "github.com/aws/aws-sdk-go-v2/service/ecr"
    awsserver "github.com/stackshy/cloudemu/v2/server/aws"
)

cloud := cloudemu.NewAWS()
ts := httptest.NewServer(awsserver.New(awsserver.Drivers{ECR: cloud.ECR}))

client := awsecr.NewFromConfig(cfg, func(o *awsecr.Options) {
    o.BaseEndpoint = aws.String(ts.URL) // the only change from real AWS
})

client.CreateRepository(ctx, &awsecr.CreateRepositoryInput{
    RepositoryName: aws.String("app"),
})
client.PutImage(ctx, &awsecr.PutImageInput{
    RepositoryName: aws.String("app"),
    ImageManifest:  aws.String(manifestJSON),
    ImageTag:       aws.String("v1"),
})
```

```go
import (
    "github.com/Azure/azure-sdk-for-go/sdk/azcore"
    azacr "github.com/Azure/azure-sdk-for-go/sdk/containers/azcontainerregistry"
    azureserver "github.com/stackshy/cloudemu/v2/server/azure"
)

cloud := cloudemu.NewAzure()
ts := httptest.NewTLSServer(azureserver.New(azureserver.Drivers{ACR: cloud.ACR}))

// Point the real azcontainerregistry client at ts (endpoint + ts.Client()).
client, _ := azacr.NewClient(ts.URL, cred, &azacr.ClientOptions{
    ClientOptions: azcore.ClientOptions{Transport: ts.Client()},
})

// ACR has no data-plane create — repositories appear on push, then you read them back.
pager := client.NewListRepositoriesPager(nil)
for pager.More() {
    page, _ := pager.NextPage(ctx)
    for _, name := range page.Repositories.Names {
        _ = *name
    }
}
```

## What each provider supports

All three drivers implement the same registry interface, so the operations line up across clouds — only the real service they stand in for differs.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

**ECR** — full repository CRUD (`CreateRepository`, `GetRepository`, `ListRepositories`, `DeleteRepository`, with `force` to delete a repository that still holds images), plus tag-mutability and scan-on-push settings on create. Images are managed with `PutImage`, `GetImage`, `ListImages`, `DeleteImage`, and `TagImage`, referenced by tag or digest. Lifecycle policies (`PutLifecyclePolicy` / `GetLifecyclePolicy` / `EvaluateLifecyclePolicy`) and image scans (`StartImageScan` / `GetImageScanResults`) round it out.

</Tab>

<Tab value="Azure">

**ACR** — the same shape as ECR: repositories via `CreateRepository` / `GetRepository` / `ListRepositories` / `DeleteRepository`, images via `PutImage` / `GetImage` / `ListImages` / `DeleteImage` / `TagImage`, addressed by tag or digest. Lifecycle policies and vulnerability scans are exposed through the same `PutLifecyclePolicy` / `EvaluateLifecyclePolicy` and `StartImageScan` / `GetImageScanResults` methods.

</Tab>

<Tab value="GCP">

**Artifact Registry** — repository and image management mirror the other two clouds: `CreateRepository` / `GetRepository` / `ListRepositories` / `DeleteRepository` for repositories, and `PutImage` / `GetImage` / `ListImages` / `DeleteImage` / `TagImage` for images. Lifecycle cleanup and image scanning use the same lifecycle-policy and scan methods.

</Tab>

</Tabs>

## How the emulator behaves

cloudemu reproduces the side effects a real registry has, not just the storage:

- **Scan-on-push is honored.** Create a repository with `ImageScanOnPush: true` and each pushed image gets a scan result you can read back with `GetImageScanResults` — no separate `StartImageScan` call needed.
- **Lifecycle policies actually evaluate.** `EvaluateLifecyclePolicy` applies the rules you set (tag status, count-more-than / since-pushed thresholds) and returns the image references that would be expired, so you can assert on cleanup logic.
- **Images are addressable by tag or digest.** `GetImage`, `DeleteImage`, and `TagImage` accept either a tag or a `sha256:` digest, and repository counts track the images they hold.

## Or call the Portable Go API directly

When you don't need the HTTP layer — for example, unit tests that construct cloudemu in-process — call its Go interface directly. The method shape is identical across clouds, so switching providers is a one-line change.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

```go
import crdriver "github.com/stackshy/cloudemu/v2/services/containerregistry/driver"

aws.ECR.CreateRepository(ctx, crdriver.RepositoryConfig{
    Name:            "my-app",
    ImageScanOnPush: true,
    Tags:            map[string]string{"team": "platform"},
})

aws.ECR.PutImage(ctx, &crdriver.ImageManifest{
    Repository: "my-app",
    Tag:        "v1.0.0",
    Digest:     "sha256:abc123...",
    SizeBytes:  10 << 20,
})

images, _ := aws.ECR.ListImages(ctx, "my-app")
```
