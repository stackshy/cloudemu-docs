## Overview

Create repositories and push images to emulated **ECR** (AWS), **ACR** (Azure), and **Artifact Registry** (GCP). Repositories, images, and tags are available through the SDK-compat server and the Portable Go API.

| Provider | Service | SDK-compat | Driver |
|----------|---------|:----------:|--------|
| AWS | ECR (repositories + images) | ✓ Live | `aws.ECR` |
| Azure | ACR (registries + repositories + tags) | ✓ Live | `azure.ACR` |
| GCP | Artifact Registry (repositories + Docker images) | ✓ Live | `gcp.ArtifactRegistry` |

## Examples

Create and list repositories through the Portable Go API:

```go
import crdriver "github.com/stackshy/cloudemu/v2/services/containerregistry/driver"

aws.ECR.CreateRepository(ctx, crdriver.RepositoryConfig{
    Name: "my-app",
    Tags: map[string]string{"team": "platform"},
})

repos, _ := aws.ECR.ListRepositories(ctx)
```

Push and list images:

```go
aws.ECR.PushImage(ctx, crdriver.PushImageInput{
    Repository: "my-app",
    Tag:        "v1.0.0",
    Digest:     "sha256:abc123...",
})

images, _ := aws.ECR.ListImages(ctx, "my-app")
```

## Notes

- **SDK-compat status:** Live. Real `aws-sdk-go-v2/service/ecr`, `armcontainerregistry`, and Artifact Registry clients can point at the [SDK-compat server](/docs/sdk-compat).
- **Lifecycle policies:** configure policies to automatically clean up old or untagged images.
- **Image scanning:** trigger vulnerability scans on pushed images.
