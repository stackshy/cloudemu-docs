Store, version, and read secrets without a real vault. cloudemu implements the **secret-management control plane** of all three clouds — creating named secrets, attaching values, rolling those values into new versions, and reading any version back. Values are held as raw bytes, so text and binary payloads round-trip unchanged, and nothing is ever written to disk or a cloud account.

| Provider | Real service | cloudemu driver |
|---|---|---|
| **AWS** | Secrets Manager | `aws.SecretsManager` |
| **Azure** | Key Vault | `azure.KeyVault` |
| **GCP** | Secret Manager | `gcp.SecretManager` |

There are two ways to drive it, both backed by the same in-memory state:

- **Real cloud SDK** — point your existing `aws-sdk-go-v2`, `azure-sdk-for-go`, or `google.golang.org/api` client at a local server. Only the endpoint changes; your real code is untouched — the same client works in a test, a local dev server, or your running app.
- **Portable Go API** — call cloudemu's Go interface directly from your application code — discover resources, perform actions, skip the HTTP hop entirely. The same method shape works across every cloud, so you can switch providers by changing one field.

## Drive it with the real SDK

cloudemu ships an HTTP server per cloud that speaks that provider's real secrets API. Run it with `httptest` in a test or behind a real `http.Server` in your app, hand it the drivers you need, and point your normal SDK client at its URL — nothing else in your code changes.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

```go
import (
    "github.com/aws/aws-sdk-go-v2/aws"
    "github.com/aws/aws-sdk-go-v2/service/secretsmanager"
    awsserver "github.com/stackshy/cloudemu/server/aws"
)

cloud := cloudemu.NewAWS()
ts := httptest.NewServer(awsserver.New(awsserver.Drivers{SecretsManager: cloud.SecretsManager}))

client := secretsmanager.NewFromConfig(cfg, func(o *secretsmanager.Options) {
    o.BaseEndpoint = aws.String(ts.URL) // the only change from real AWS
})

client.CreateSecret(ctx, &secretsmanager.CreateSecretInput{
    Name:         aws.String("db-password"),
    SecretString: aws.String("hunter2"),
})
```

</Tab>

```go
import (
    "github.com/Azure/azure-sdk-for-go/sdk/azcore/to"
    "github.com/Azure/azure-sdk-for-go/sdk/security/keyvault/azsecrets"
    azureserver "github.com/stackshy/cloudemu/server/azure"
)

cloud := cloudemu.NewAzure()
ts := httptest.NewTLSServer(azureserver.New(azureserver.Drivers{KeyVault: cloud.KeyVault}))

// Point the real azsecrets client at ts (URL + ts.Client()).
client, _ := azsecrets.NewClient(ts.URL, cred, optsFor(ts))

client.SetSecret(ctx, "db-password", azsecrets.SetSecretParameters{
    Value: to.Ptr("hunter2"),
}, nil)
```

```go
import (
    "google.golang.org/api/option"

svc, _ := secretmanager.NewService(ctx,

    option.WithoutAuthentication(),
)

svc.Projects.Secrets.Create("projects/demo", &secretmanager.Secret{
    Replication: &secretmanager.Replication{Automatic: &secretmanager.Automatic{}},
}).SecretId("db-password").Context(ctx).Do()
```

## What each provider supports

Every provider exposes the same operations, mapped onto the real service's own vocabulary.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

**Secrets Manager** — `CreateSecret`, `GetSecret` (metadata), `ListSecrets`, and `DeleteSecret`, plus the value operations `PutSecretValue`, `GetSecretValue`, and `ListSecretVersions`. Each `PutSecretValue` stages a new current version, matching how Secrets Manager promotes the `AWSCURRENT` label.

</Tab>

<Tab value="Azure">

**Key Vault** — the same set: `CreateSecret`, `GetSecret`, `ListSecrets`, `DeleteSecret`, and value-level `PutSecretValue` / `GetSecretValue` / `ListSecretVersions`. Setting a new value creates a new secret version, exactly as Key Vault does on `SetSecret`.

</Tab>

<Tab value="GCP">

**Secret Manager** — `CreateSecret`, `GetSecret`, `ListSecrets`, and `DeleteSecret`, with `PutSecretValue`, `GetSecretValue`, and `ListSecretVersions` covering the secret-version model. Each stored value corresponds to a version you can access by ID, like accessing a specific version of a GCP secret.

</Tab>

</Tabs>

## How the emulator behaves

cloudemu reproduces the metadata/value split and versioning semantics of the real services, so your code exercises realistic behavior rather than a flat key-value store:

- **Every value is a version.** `CreateSecret` seeds the first version and each `PutSecretValue` adds another, marking it current; older versions stay retained and are addressable by their `VersionID` through `GetSecretValue`.
- **Current is implicit.** Calling `GetSecretValue` with an empty `versionID` returns whichever version is current, so callers that only ever want "the latest" never have to track version IDs.
- **Binary-safe.** Values are stored as `[]byte`, so arbitrary binary payloads — keys, certificates, encoded blobs — round-trip byte-for-byte, not just UTF-8 strings.

## Or call the Portable Go API directly

The method shape is identical across clouds, so switching providers is a one-line change — swap the driver field.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

```go
aws.SecretsManager.CreateSecret(ctx, secdriver.SecretConfig{Name: "api-key"}, []byte("k-123"))
versions, _ := aws.SecretsManager.ListSecretVersions(ctx, "api-key")
```

</Tab>

<Tab value="Azure">

```go
azure.KeyVault.CreateSecret(ctx, secdriver.SecretConfig{Name: "api-key"}, []byte("k-123"))
versions, _ := azure.KeyVault.ListSecretVersions(ctx, "api-key")
```

</Tab>

<Tab value="GCP">

```go
gcp.SecretManager.CreateSecret(ctx, secdriver.SecretConfig{Name: "api-key"}, []byte("k-123"))
versions, _ := gcp.SecretManager.ListSecretVersions(ctx, "api-key")
```
