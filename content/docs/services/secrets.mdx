## Overview

Create, version, and read secrets in emulated **SecretsManager** (AWS), **KeyVault** (Azure), and **SecretManager** (GCP). Secret versions, rotation, and binary payloads are available through the Portable Go API.

| Provider | Service | SDK-compat | Driver |
|----------|---------|:----------:|--------|
| AWS | Secrets Manager | — | `aws.SecretsManager` |
| Azure | Key Vault | — | `azure.KeyVault` |
| GCP | Secret Manager | — | `gcp.SecretManager` |

## Examples

Create a secret:

```go
import secdriver "github.com/stackshy/cloudemu/v2/services/secrets/driver"

aws.SecretsManager.CreateSecret(ctx, secdriver.SecretConfig{
    Name:  "db-password",
    Value: "super-secret-123",
    Tags:  map[string]string{"env": "production"},
})
```

Read a secret:

```go
secret, _ := aws.SecretsManager.GetSecret(ctx, "db-password")
fmt.Println(secret.Value) // "super-secret-123"
```

Update a secret to create a new version, and read a specific version:

```go
// Update creates a new version
aws.SecretsManager.UpdateSecret(ctx, "db-password", "new-password-456")

// Get specific version
secret, _ = aws.SecretsManager.GetSecretVersion(ctx, "db-password", "v2")
```

List secrets:

```go
secrets, _ := aws.SecretsManager.ListSecrets(ctx)
```

## Notes

- **SDK-compat status:** Portable Go API only. Real `aws-sdk-go-v2/service/secretsmanager`, `azsecrets`, and Secret Manager REST clients can't talk to cloudemu yet — secrets SDK-compat handlers are next on the roadmap.
