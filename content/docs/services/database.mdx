Model a NoSQL database entirely in memory. cloudemu implements the **document / key-value data plane** of all three clouds — creating tables and containers, writing and reading items, querying and scanning, batching, and the indexes and streams around them. The exact SDK code you'd write against real DynamoDB, Cosmos DB, or Firestore runs against a local server instead: no table is ever provisioned, nothing is billed, and every call returns in milliseconds.

| Provider | Real service | cloudemu driver |
|---|---|---|
| **AWS** | DynamoDB — tables, items, queries, GSIs, streams | `aws.DynamoDB` |
| **Azure** | Cosmos DB — databases, containers, documents | `azure.CosmosDB` |
| **GCP** | Firestore — collections, documents, queries | `gcp.Firestore` |

There are two ways to drive it, both backed by the same in-memory state:

- **Real cloud SDK** — point your existing `aws-sdk-go-v2`, `azcosmos`, or `cloud.google.com/go/firestore` client at a local server. Only the endpoint changes; your real code is untouched — the same client works in a test, a local dev server, or your running app.
- **Portable Go API** — call cloudemu's Go interface directly from your application code — discover resources, perform actions, skip the HTTP hop entirely. The same method shape works across every cloud, so you can switch providers by changing one field.

## Drive it with the real SDK

cloudemu ships an HTTP server per cloud that speaks that provider's real wire protocol. Run it with `httptest` in a test or behind a real `http.Server` in your app, hand it the drivers you need, and point your normal SDK client at its URL — nothing else in your code changes.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

```go
import (
    "github.com/aws/aws-sdk-go-v2/service/dynamodb"
    "github.com/aws/aws-sdk-go-v2/service/dynamodb/types"
    awsserver "github.com/stackshy/cloudemu/server/aws"
)

cloud := cloudemu.NewAWS()
ts := httptest.NewServer(awsserver.New(awsserver.Drivers{DynamoDB: cloud.DynamoDB}))

client := dynamodb.NewFromConfig(cfg, func(o *dynamodb.Options) {
    o.BaseEndpoint = aws.String(ts.URL) // the only change from real AWS
})

client.CreateTable(ctx, &dynamodb.CreateTableInput{
    TableName: aws.String("Users"),
    AttributeDefinitions: []types.AttributeDefinition{
        {AttributeName: aws.String("id"), AttributeType: types.ScalarAttributeTypeS},
    },
    KeySchema: []types.KeySchemaElement{
        {AttributeName: aws.String("id"), KeyType: types.KeyTypeHash},
    },
    BillingMode: types.BillingModePayPerRequest,
})

client.PutItem(ctx, &dynamodb.PutItemInput{
    TableName: aws.String("Users"),
    Item: map[string]types.AttributeValue{
        "id":   &types.AttributeValueMemberS{Value: "u1"},
        "name": &types.AttributeValueMemberS{Value: "Alice"},
    },
})
```

```go
import (
    "github.com/Azure/azure-sdk-for-go/sdk/data/azcosmos"
    azureserver "github.com/stackshy/cloudemu/server/azure"

cloud := cloudemu.NewAzure()
ts := httptest.NewTLSServer(azureserver.New(azureserver.Drivers{
    CosmosDB: cloud.CosmosDB,
}))

// The Cosmos SDK requires TLS; point the real azcosmos client at ts.
cred, _ := azcosmos.NewKeyCredential(key)
client, _ := azcosmos.NewClientWithKey(ts.URL, cred, optsFor(ts))

client.CreateDatabase(ctx, azcosmos.DatabaseProperties{ID: "app"}, nil)
db, _ := client.NewDatabase("app")
db.CreateContainer(ctx, azcosmos.ContainerProperties{
    ID:                     "Users",
    PartitionKeyDefinition: azcosmos.PartitionKeyDefinition{Paths: []string{"/pk"}},
}, nil)

cc, _ := db.NewContainer("Users")
item, _ := json.Marshal(map[string]any{"id": "u1", "pk": "u1", "name": "Alice"})
cc.CreateItem(ctx, azcosmos.NewPartitionKeyString("u1"), item, nil)
```

## What each provider supports

Not every provider exposes the same operations — cloudemu matches what each cloud's own API offers.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

**DynamoDB** — table lifecycle with `CreateTable`, `DeleteTable`, `DescribeTable`, and `ListTables`. Item operations cover `PutItem`, `GetItem`, `DeleteItem`, and `UpdateItem` (SET / REMOVE), plus `Query` and `Scan` with `FilterExpression`. Batch and transactional writes are supported via `BatchWriteItem`, `BatchGetItem`, and `TransactWriteItems`.

</Tab>

<Tab value="Azure">

**Cosmos DB** — the document data plane over databases, containers, and documents, with full CRUD and query. Requests carry the real `x-ms-documentdb-*` headers and partition-key routing, so the `azcosmos` SDK behaves as it does against a real account.

</Tab>

<Tab value="GCP">

**Firestore** — the REST data plane: document CRUD alongside `:commit` (batched writes), `:batchGet` (batched reads), and `:runQuery`. Writing into a not-yet-existent collection auto-creates it, matching real Firestore.

</Tab>

</Tabs>

## How the emulator behaves

cloudemu doesn't just store objects — it reproduces the side effects of the real service, so your code exercises realistic behavior instead of a dumb key-value store:

- **TTL expiry.** Items with a TTL attribute expire on read, so your code can advance the clock and see the row disappear without a background sweeper.
- **Numeric-aware comparisons.** Filters compare numbers by value, not lexically — `"10" > "9"` evaluates correctly.
- **Streams and change feeds.** With streams enabled, `PutItem` / `UpdateItem` / `DeleteItem` emit INSERT / MODIFY / REMOVE records. Global Secondary Indexes are managed with `CreateIndex`, `DescribeIndex`, and `DeleteIndex`, and queries target one via `QueryInput.IndexName`.

## Or call the Portable Go API directly

When you don't need the HTTP layer, call cloudemu's Go interface directly inside your application — discovery, provisioning, teardown — no server, no wire protocol. The method shape is identical across clouds, so switching providers is a one-line change.

<Tab value="AWS">

```go
aws.DynamoDB.CreateTable(ctx, dbdriver.TableConfig{
    Name: "Users", PartitionKey: "id",
})
aws.DynamoDB.PutItem(ctx, "Users", map[string]any{"id": "u1", "name": "Alice"})
item, _ := aws.DynamoDB.GetItem(ctx, "Users", map[string]any{"id": "u1"})
```
