---
title: Cache
description: Emulate ElastiCache, Azure Cache for Redis, and Memorystore as an in-memory key-value cache with real TTL expiry.
---

Store and expire cached values entirely in memory. cloudemu emulates the **cache management and data plane** of all three clouds — creating cache instances, then setting, reading, and deleting keyed values with time-to-live. Items expire on their own and every call returns in milliseconds, so code that depends on caching behaviour never needs Redis, Memcached, or a real cloud account.

| Provider | Real service | cloudemu driver |
|---|---|---|
| **AWS** | ElastiCache | `aws.ElastiCache` |
| **Azure** | Cache for Redis | `azure.Cache` |
| **GCP** | Memorystore | `gcp.Memorystore` |

There are two ways to drive it, both backed by the same in-memory state:

- **Real cloud SDK** — point your existing `aws-sdk-go-v2`, `azure-sdk-for-go`, or `google.golang.org/api` client at a local server. Only the endpoint changes; your real code is untouched — the same client works in a test, a local dev server, or your running app.
- **Portable Go API** — call cloudemu's Go interface directly from your application code — discover resources, perform actions, skip the HTTP hop entirely. The same method shape works across every cloud, so you can switch providers by changing one field.

## Drive it with the real SDK

cloudemu ships an HTTP server per cloud that speaks that provider's real cache management API. Run it with `httptest` in a test or behind a real `http.Server` in your app, hand it the drivers you need, and point your normal SDK client at its URL — nothing else in your code changes.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

```go
import (
    "github.com/aws/aws-sdk-go-v2/aws"
    "github.com/aws/aws-sdk-go-v2/service/elasticache"
    awsserver "github.com/stackshy/cloudemu/server/aws"
)

cloud := cloudemu.NewAWS()
ts := httptest.NewServer(awsserver.New(awsserver.Drivers{ElastiCache: cloud.ElastiCache}))

client := elasticache.NewFromConfig(cfg, func(o *elasticache.Options) {
    o.BaseEndpoint = aws.String(ts.URL) // the only change from real AWS
})

client.CreateCacheCluster(ctx, &elasticache.CreateCacheClusterInput{
    CacheClusterId: aws.String("session-cache"),
    Engine:         aws.String("redis"),
    CacheNodeType:  aws.String("cache.t3.micro"),
    NumCacheNodes:  aws.Int32(1),
})
```

## What each provider supports

Every provider exposes the same shape: create a cache instance, then set, get, and delete keyed values with an optional TTL.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

**ElastiCache** — `CreateCache` to provision a cache (with a node type such as `cache.t3.micro`), then `Set` a value with a TTL, `Get` it back, and `Delete` it by key.

</Tab>

<Tab value="Azure">

**Cache for Redis** — the same lifecycle: `CreateCache` to provision the cache, then `Set` / `Get` / `Delete` against keyed values with TTL support.

</Tab>

<Tab value="GCP">

**Memorystore** — `CreateCache` provisions the instance, and `Set` / `Get` / `Delete` manage keyed values with the same TTL semantics as the other providers.

</Tab>

</Tabs>

## How the emulator behaves

cloudemu reproduces the parts of caching your code actually depends on, not just a plain map:

- **TTL is enforced.** Items are expired once their TTL elapses, with lazy cleanup on the next read — so your code can set a short TTL and assert the value is gone afterward.
- **Concurrency is safe.** All cache operations are guarded for concurrent access, so parallel readers and writers behave predictably.

## Or call the Portable Go API directly

Call cloudemu's Go interface directly and skip the HTTP hop. The method shape is identical across clouds, so switching providers is a one-line change.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

```go
import cachedriver "github.com/stackshy/cloudemu/cache/driver"

aws.ElastiCache.CreateCache(ctx, cachedriver.CacheConfig{
    Name: "session-cache", NodeType: "cache.t3.micro",
})
aws.ElastiCache.Set(ctx, "session-cache", "user:123", []byte("session-data"), 30*time.Minute)
data, _ := aws.ElastiCache.Get(ctx, "session-cache", "user:123")
aws.ElastiCache.Delete(ctx, "session-cache", "user:123")
```

</Tab>
