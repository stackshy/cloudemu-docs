title: Logging
description: Emulate CloudWatch Logs, Log Analytics, and Cloud Logging — log groups, streams, and filter queries entirely in memory.
---

Capture and query application logs without a real logging backend. cloudemu implements the **log ingestion and query surface** of all three clouds — creating log groups, opening streams inside them, writing events, and reading them back with time-range and pattern filters. Everything lives in memory: no agent, no network hop, no bill, and every query returns in milliseconds.

| Provider | Real service | cloudemu driver |
|---|---|---|
| **AWS** | CloudWatch Logs | `aws.CloudWatchLogs` |
| **Azure** | Log Analytics | `azure.LogAnalytics` |
| **GCP** | Cloud Logging | `gcp.CloudLogging` |

There are two ways to drive it, both backed by the same in-memory state:

- **Real cloud SDK** — point your existing `aws-sdk-go-v2`, `azure-sdk-for-go`, or `google.golang.org/api` client at a local server. Only the endpoint changes; your real code is untouched — the same client works in a test, a local dev server, or your running app.
- **Portable Go API** — call cloudemu's Go interface directly from your application code — discover resources, perform actions, skip the HTTP hop entirely. The same method shape works across every cloud, so you can switch providers by changing one field.

## Drive it with the real SDK

cloudemu ships an HTTP server per cloud that speaks that provider's real wire protocol — start it with `httptest`, hand it the drivers you need, and point your normal SDK client at its URL.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

```go
import (
    "github.com/aws/aws-sdk-go-v2/aws"
    "github.com/aws/aws-sdk-go-v2/service/cloudwatchlogs"
    cwltypes "github.com/aws/aws-sdk-go-v2/service/cloudwatchlogs/types"
    awsserver "github.com/stackshy/cloudemu/server/aws"
)

cloud := cloudemu.NewAWS()
ts := httptest.NewServer(awsserver.New(awsserver.Drivers{CloudWatchLogs: cloud.CloudWatchLogs}))

client := cloudwatchlogs.NewFromConfig(cfg, func(o *cloudwatchlogs.Options) {
    o.BaseEndpoint = aws.String(ts.URL) // the only change from real AWS
})

client.CreateLogGroup(ctx, &cloudwatchlogs.CreateLogGroupInput{
    LogGroupName: aws.String("/app/api"),
})
client.CreateLogStream(ctx, &cloudwatchlogs.CreateLogStreamInput{
    LogGroupName:  aws.String("/app/api"),
    LogStreamName: aws.String("instance-1"),
})
client.PutLogEvents(ctx, &cloudwatchlogs.PutLogEventsInput{
    LogGroupName:  aws.String("/app/api"),
    LogStreamName: aws.String("instance-1"),
    LogEvents: []cwltypes.InputLogEvent{
        {Timestamp: aws.Int64(time.Now().UnixMilli()), Message: aws.String("hello world")},
    },
})
```

## What each provider supports

All three drivers expose the same logging surface — cloudemu keeps the behavior consistent across clouds.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

**Log groups** — `CreateLogGroup`, `UpdateLogGroup` (retention and tags), `GetLogGroup`, `ListLogGroups`, and `DeleteLogGroup`. **Log streams** — `CreateLogStream`, `ListLogStreams`, and `DeleteLogStream` inside a group.

**Events** — write with `PutLogEvents`, read with `GetLogEvents` (time range, stream, pattern, limit), and search across streams with `FilterLogEvents`. **Metric filters** — define pattern-to-metric mappings with `PutMetricFilter`, `DescribeMetricFilters`, and `DeleteMetricFilter`.

</Tab>

<Tab value="Azure">

**Log groups** — `CreateLogGroup`, `UpdateLogGroup` (retention and tags, mirroring ARM CreateOrUpdate-on-existing), `GetLogGroup`, `ListLogGroups`, and `DeleteLogGroup`. **Log streams** — `CreateLogStream`, `ListLogStreams`, and `DeleteLogStream`.

**Events** — `PutLogEvents` to ingest, `GetLogEvents` to read a stream by time range and pattern, and `FilterLogEvents` to search across streams. **Metric filters** — `PutMetricFilter`, `DescribeMetricFilters`, and `DeleteMetricFilter`.

</Tab>

<Tab value="GCP">

**Log groups** — `CreateLogGroup`, `UpdateLogGroup` (retention and tags), `GetLogGroup`, `ListLogGroups`, and `DeleteLogGroup`. **Log streams** — `CreateLogStream`, `ListLogStreams`, and `DeleteLogStream`.

**Events** — `PutLogEvents` to write, `GetLogEvents` to read a stream by time range and pattern, and `FilterLogEvents` to search across streams. **Metric filters** — `PutMetricFilter`, `DescribeMetricFilters`, and `DeleteMetricFilter`.

</Tab>

</Tabs>

## How the emulator behaves

cloudemu reproduces the side effects of a real logging service, not just a key-value store:

- **Retention is enforced on read.** Each group has a retention window (default 30 days); events older than the cutoff are filtered out of `GetLogEvents` results, exactly like the real service ages logs out.
- **Ingestion emits metrics.** `PutLogEvents` automatically pushes `IncomingLogEvents` and `IncomingBytes` into the monitoring service, so your code can assert on log-ingestion metrics without extra wiring.
- **Stored bytes are tracked.** Each `PutLogEvents` call adds to the group's `StoredBytes`, so you can assert on how much a group has accumulated.

## Or call the Portable Go API directly

When you don't need the HTTP layer, call cloudemu's Go interface directly inside your application — discovery, provisioning, teardown — no server, no wire protocol. The method shape is identical across clouds, so switching providers is a one-line change.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

```go
import logdriver "github.com/stackshy/cloudemu/services/logging/driver"

aws.CloudWatchLogs.CreateLogGroup(ctx, logdriver.LogGroupConfig{
    Name:          "/app/web",
    RetentionDays: 30,
})
aws.CloudWatchLogs.CreateLogStream(ctx, "/app/web", "instance-001")

aws.CloudWatchLogs.PutLogEvents(ctx, "/app/web", "instance-001", []logdriver.LogEvent{
    {Timestamp: time.Now(), Message: "Server started on port 8080"},
    {Timestamp: time.Now(), Message: "Handling request GET /api/users"},
})

events, _ := aws.CloudWatchLogs.GetLogEvents(ctx, &logdriver.LogQueryInput{
    LogGroup:  "/app/web",
    LogStream: "instance-001",
    StartTime: time.Now().Add(-1 * time.Hour),
    Limit:     100,
})
```
