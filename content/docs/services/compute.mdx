title: Compute
description: Emulate EC2, Azure VMs, and Compute Engine — drive them with the real cloud SDK.

Launch and manage virtual machines entirely in memory. cloudemu implements the **compute control plane** of all three clouds — creating instances, listing and describing them, starting and stopping them, and the network and disk resources around them. The exact SDK code you'd write against real AWS, Azure, or GCP runs against a local server instead: no VM is ever booted, nothing is billed, and every call returns in milliseconds.

| Provider | Real service | cloudemu driver |
|---|---|---|
| **AWS** | EC2 — instances + the full VPC stack | `aws.EC2` |
| **Azure** | Virtual Machines — plus Disks, Snapshots, Images, SSH keys | `azure.VirtualMachines` |
| **GCP** | Compute Engine — plus Disks, Snapshots, Images | `gcp.GCE` |

There are two ways to drive it, both backed by the same in-memory state:

- **Real cloud SDK** — point your existing `aws-sdk-go-v2`, `azure-sdk-for-go`, or `cloud.google.com/go` client at a local server. Only the endpoint changes; your production code is untouched. This is the closest thing to testing against the real cloud, and what most tests should use.
- **Portable Go API** — call cloudemu's Go interface directly and skip the HTTP hop. The same method shape works across every cloud, so you can switch providers by changing one field.

## Drive it with the real SDK

cloudemu ships an HTTP server per cloud that speaks that provider's real wire protocol. You start it with `httptest`, hand it the drivers you need, and point your normal SDK client at its URL — nothing else in your code changes.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

```go
import (
    "github.com/aws/aws-sdk-go-v2/service/ec2"
    "github.com/aws/aws-sdk-go-v2/service/ec2/types"
    awsserver "github.com/stackshy/cloudemu/server/aws"
)

cloud := cloudemu.NewAWS()
ts := httptest.NewServer(awsserver.New(awsserver.Drivers{EC2: cloud.EC2, VPC: cloud.VPC}))

client := ec2.NewFromConfig(cfg, func(o *ec2.Options) {
    o.BaseEndpoint = aws.String(ts.URL) // the only change from real AWS
})

out, _ := client.RunInstances(ctx, &ec2.RunInstancesInput{
    ImageId:      aws.String("ami-0abcdef1234"),
    InstanceType: types.InstanceTypeT3Large,
    MinCount:     aws.Int32(1),
    MaxCount:     aws.Int32(3),
})
client.StopInstances(ctx, &ec2.StopInstancesInput{
    InstanceIds: []string{*out.Instances[0].InstanceId},
})
```

</Tab>

<Tab value="Azure">

```go
import (
    "github.com/Azure/azure-sdk-for-go/sdk/resourcemanager/compute/armcompute/v5"
    azureserver "github.com/stackshy/cloudemu/server/azure"
)

cloud := cloudemu.NewAzure()
ts := httptest.NewTLSServer(azureserver.New(azureserver.Drivers{
    VirtualMachines: cloud.VirtualMachines,
}))

// Point the real armcompute client at ts (endpoint + ts.Client()).
client, _ := armcompute.NewVirtualMachinesClient("sub-1", cred, optsFor(ts))

poller, _ := client.BeginCreateOrUpdate(ctx, "my-rg", "vm-1", armcompute.VirtualMachine{
    Location: to.Ptr("eastus"),
    Properties: &armcompute.VirtualMachineProperties{
        HardwareProfile: &armcompute.HardwareProfile{
            VMSize: to.Ptr(armcompute.VirtualMachineSizeTypesStandardD2SV3),
        },
    },
}, nil)
vm, _ := poller.PollUntilDone(ctx, nil)
```

<Tab value="GCP">

```go
import (
    compute "cloud.google.com/go/compute/apiv1"
    "cloud.google.com/go/compute/apiv1/computepb"
    gcpserver "github.com/stackshy/cloudemu/server/gcp"
)

cloud := cloudemu.NewGCP()
ts := httptest.NewServer(gcpserver.New(gcpserver.Drivers{Compute: cloud.GCE}))

client, _ := compute.NewInstancesRESTClient(ctx,
    option.WithEndpoint(ts.URL), // the only change from real GCP
    option.WithoutAuthentication(),
    option.WithHTTPClient(ts.Client()),
)

op, _ := client.Insert(ctx, &computepb.InsertInstanceRequest{
    Project: "my-project",
    Zone:    "us-central1-a",
    InstanceResource: &computepb.Instance{
        Name:        proto.String("vm-1"),
        MachineType: proto.String("zones/us-central1-a/machineTypes/e2-standard-2"),
    },
})
op.Wait(ctx)
```

## What each provider supports

Not every provider exposes the same operations — cloudemu matches what each cloud's own API offers.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

**EC2 instances** — `RunInstances`, `DescribeInstances` (filter by `instance-id`, `instance-type`, `instance-state-name`, or `tag:*`), `Start` / `Stop` / `Reboot` / `TerminateInstances`, and `ModifyInstanceAttribute`.

**The VPC stack** — VPCs, subnets, security groups (with ingress/egress rules), internet and NAT gateways, route tables, peering, flow logs, network ACLs, EBS volumes, key pairs, snapshots, AMIs, spot instances, launch templates, and auto-scaling groups. Enough to model a realistic network around your instances.

</Tab>

<Tab value="Azure">

**Virtual Machines** — `CreateOrUpdate`, `Get`, `List`, and `Delete`, plus the `start` / `powerOff` / `restart` power actions. Around them, full CRUD for **Disks**, **Snapshots**, **Images**, and **SSH public keys** — the resources you attach to and provision a VM with.

</Tab>

<Tab value="GCP">

**Compute Engine** — Instances, Disks, Snapshots, and Images, each with `insert` / `get` / `list` / `delete`. Every mutating call returns a **long-running-operation (LRO)** envelope and completes synchronously, so `op.Wait(ctx)` behaves the same as it does against real GCP.

</Tab>

</Tabs>

## How the emulator behaves

cloudemu doesn't just store objects — it reproduces the lifecycle and side effects of the real service, so your tests exercise realistic behavior instead of a dumb key-value store:

- **Lifecycle is enforced.** An instance moves through `pending → running → stopped → terminated`. Ask for an illegal transition — stopping an already-terminated instance, say — and you get an error back, exactly like real EC2.
- **Metrics appear on their own.** `RunInstances` automatically pushes CPU, network, and disk metrics into the monitoring service, and start / stop / reboot / terminate each emit matching values. So a test that creates an instance can immediately assert on its metrics without any extra setup.

## Or call the Portable Go API directly

When you don't need the HTTP layer — for example, unit tests that construct cloudemu in-process — call its Go interface directly. The method shape is identical across clouds, so switching providers is a one-line change.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

```go
ids, _ := aws.EC2.RunInstances(ctx, computedriver.InstanceConfig{
    ImageID: "ami-0abcdef1234", InstanceType: "t3.large",
}, 3)
aws.EC2.StopInstances(ctx, ids)
```

</Tab>

<Tab value="Azure">

```go
ids, _ := azure.VirtualMachines.RunInstances(ctx, computedriver.InstanceConfig{
    ImageID: "Ubuntu-22.04", InstanceType: "Standard_D2s_v3",
}, 3)
azure.VirtualMachines.StopInstances(ctx, ids)
```

</Tab>

```go
ids, _ := gcp.GCE.RunInstances(ctx, computedriver.InstanceConfig{
```
