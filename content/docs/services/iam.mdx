Model identity, roles, and access policies entirely in memory. cloudemu implements the **identity and access-management control plane** of all three clouds — creating users, roles, and service accounts, attaching and versioning policies, managing groups and keys, and evaluating whether a principal is allowed to perform an action. The exact SDK code you'd write against real AWS, Azure, or GCP runs against a local server instead: nothing touches a real account, and every call returns in milliseconds.

| Provider | Real service | cloudemu driver |
|---|---|---|
| **AWS** | IAM — users, roles, policies, groups, access keys, instance profiles | `aws.IAM` |
| **Azure** | Role-Based Access Control — role definitions + role assignments | `azure.IAM` |
| **GCP** | Cloud IAM — service accounts, custom roles, service-account keys | `gcp.IAM` |

There are two ways to drive it, both backed by the same in-memory state:

- **Real cloud SDK** — point your existing `aws-sdk-go-v2`, `azure-sdk-for-go`, or `google.golang.org/api` client at a local server. Only the endpoint changes; your real code is untouched — the same client works in a test, a local dev server, or your running app.
- **Portable Go API** — call cloudemu's Go interface directly from your application code — discover resources, perform actions, skip the HTTP hop entirely. The same method shape works across every cloud, so you can switch providers by changing one field.

## Drive it with the real SDK

cloudemu ships an HTTP server per cloud that speaks that provider's real wire protocol. Run it with `httptest` in a test or behind a real `http.Server` in your app, hand it the drivers you need, and point your normal SDK client at its URL — nothing else in your code changes.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

```go
import (
    "github.com/aws/aws-sdk-go-v2/service/iam"
    awsserver "github.com/stackshy/cloudemu/server/aws"
)

cloud := cloudemu.NewAWS()
ts := httptest.NewServer(awsserver.New(awsserver.Drivers{IAM: cloud.IAM}))

client := iam.NewFromConfig(cfg, func(o *iam.Options) {
    o.BaseEndpoint = aws.String(ts.URL) // the only change from real AWS
})

out, _ := client.CreateUser(ctx, &iam.CreateUserInput{
    UserName: aws.String("alice"),
    Path:     aws.String("/team/"),
})
_ = out.User.UserName
```

```go
import (

    azureserver "github.com/stackshy/cloudemu/server/azure"
)

cloud := cloudemu.NewAzure()
ts := httptest.NewTLSServer(azureserver.New(azureserver.Drivers{IAM: cloud.IAM}))

// Point the real armauthorization client at ts (endpoint + ts.Client()).
cf, _ := armauthorization.NewClientFactory("sub-1", cred, optsFor(ts))
roleDefs := cf.NewRoleDefinitionsClient()

roleDefs.CreateOrUpdate(ctx, scope, roleID, armauthorization.RoleDefinition{
    Properties: &armauthorization.RoleDefinitionProperties{
        RoleName: to.Ptr("Custom Reader"),
        RoleType: to.Ptr("CustomRole"),
        Permissions: []*armauthorization.Permission{{
            Actions: []*string{to.Ptr("Microsoft.Compute/virtualMachines/read")},
        }},
        AssignableScopes: []*string{to.Ptr(scope)},
    },
}, nil)
```

## What each provider supports

Not every provider models identity the same way — cloudemu matches what each cloud's own API offers.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

**Users and roles** — `CreateUser` / `GetUser` / `ListUsers` / `DeleteUser`, and `CreateRole` with an assume-role trust policy, plus inline role policies via `PutRolePolicy` / `GetRolePolicy` / `ListRolePolicies` / `DeleteRolePolicy`.

**Managed policies** — `CreatePolicy`, `AttachRolePolicy` / `DetachRolePolicy` / `ListAttachedRolePolicies`, and a full policy-version lifecycle (`CreatePolicyVersion`, `SetDefaultPolicyVersion`, `ListPolicyVersions`, `GetPolicyVersion`).

**Groups, keys, and profiles** — group creation and membership (`CreateGroup`, `AddUserToGroup`, `ListGroupsForUser`), access keys (`CreateAccessKey` / `ListAccessKeys` / `DeleteAccessKey`), and instance profiles that bind a role to compute.

</Tab>

<Tab value="Azure">

**Role definitions** — `CreateOrUpdate`, `Get`, `List`, and `Delete` for custom roles, each carrying `Actions` / `NotActions` permission sets and a list of assignable scopes.

**Role assignments** — `Create`, `Get`, `Delete`, and list-for-scope, binding a principal to a role definition at a subscription or resource scope, exactly as Azure RBAC does.

</Tab>

<Tab value="GCP">

**Service accounts** — `Create`, `Get`, `List`, and `Delete`, plus `Disable` / `Enable`, `SignBlob`, and per-account `GetIamPolicy` / `SetIamPolicy`.

**Keys and roles** — service-account keys (`Keys.Create` returns `PrivateKeyData` once, like real GCP, then `List` / `Delete`), and custom project roles with `IncludedPermissions` via `Roles.Create` / `Get` / `List` / `Delete`.

</Tab>

</Tabs>

## How the emulator behaves

cloudemu doesn't just store policy JSON — it reproduces the evaluation and error semantics of the real services, so your code exercises realistic behavior instead of a dumb key-value store:

- **Policies are actually evaluated.** `CheckPermission` parses JSON policy documents, matches wildcards in actions and resources (`s3:*`, `arn:aws:s3:::*`), and honors real precedence — an explicit `Deny` always overrides an `Allow`.
- **Errors are typed like the real API.** A missing entity surfaces as `NoSuchEntity` (HTTP 404 on GCP), deleting a policy's default version raises `DeleteConflict`, and exceeding five policy versions raises `LimitExceeded` — the same exceptions your production error handling already catches.
- **Managed-policy versioning matches AWS.** `CreatePolicy` auto-seeds a default `v1`, new versions can be set as default, the default version can't be deleted, and the version count is capped at five.

## Or call the Portable Go API directly

When you don't need the HTTP layer, call cloudemu's Go interface directly inside your application — discovery, provisioning, teardown — no server, no wire protocol. The method shape is identical across clouds, so switching providers is a one-line change.

<Tabs items={['AWS', 'Azure', 'GCP']}>

<Tab value="AWS">

```go
aws.IAM.CreateUser(ctx, iamdriver.UserConfig{
    Name: "alice", Tags: map[string]string{"team": "backend"},
})
allowed, _ := aws.IAM.CheckPermission(ctx, "alice", "s3:GetObject", "arn:aws:s3:::my-bucket/file.txt")
```

</Tab>
