Find any emulated service across **AWS, Azure, GCP, and OCI**, and whether it speaks the real SDK wire format. cloudemu emulates **177 service interfaces spanning 4,000+ operations** — **76 AWS · 77 Azure · 57 GCP · 10 OCI** service implementations. Most core categories are implemented for AWS, Azure, and GCP, and OCI covers the core set marked below; the rest are provider-specific, matching where the real service exists (ECS, MemoryDB, and Keyspaces on AWS; Managed Cassandra and Azure AI on Azure; Bigtable and Vertex AI on GCP; and so on).

The **SDK-compat** column shows whether a category has an HTTP wire-format handler that real cloud SDKs (`aws-sdk-go-v2`, `azure-sdk-for-go`, `cloud.google.com/go`, `oci-go-sdk`, `databricks-sdk-go`) can talk to with only an endpoint change. See the [SDK-Compatible Server](/docs/sdk-compat) page for the full operation tables. Every service below speaks its cloud's real wire protocol.

## Accessing Services

Each provider exposes services as typed fields:

```go
aws := cloudemu.NewAWS()
aws.EC2           // Compute
aws.S3            // Storage
aws.DynamoDB      // Database (NoSQL)
aws.RDS           // Relational DB
aws.Lambda        // Serverless
aws.EKS           // Kubernetes
aws.ECS           // Container Orchestration
aws.VPC           // Networking
aws.CloudWatch    // Monitoring
aws.SSM           // Parameter Store
aws.Bedrock       // Generative AI
aws.Athena        // Analytics
aws.KMS           // Key management

azure := cloudemu.NewAzure()
azure.VirtualMachines  // Compute
azure.CosmosDB         // Database (NoSQL)
azure.AKS              // Kubernetes
azure.AI               // Azure OpenAI / AI
azure.Databricks       // Databricks
azure.TableStorage     // Table Storage
azure.DataFactory      // Data integration
azure.Firewall         // Azure Firewall

gcp := cloudemu.NewGCP()
gcp.GCE               // Compute
gcp.Firestore         // Database (NoSQL)
gcp.CloudSQL          // Relational DB
gcp.GKE               // Kubernetes
gcp.Bigtable          // Bigtable
gcp.VertexAI          // Machine Learning
gcp.Spanner           // Spanner
gcp.Dataproc          // Analytics

oci := cloudemu.NewOCI()
oci.Compute           // Compute + Block Volume
oci.ObjectStorage     // Storage
oci.NoSQL             // Database (NoSQL)
oci.VCN               // Networking
oci.Identity          // IAM
oci.Vault             // Secrets
oci.Logging           // Logging
oci.Monitoring        // Monitoring
oci.Notifications     // Notification
```

All providers implement the same driver interfaces, so operations and behaviors are consistent across clouds. On OCI, a service it doesn't emulate yet (Functions, Queue, Load Balancer, DNS, Container Registry, Cache, Events, MySQL/PostgreSQL, OKE) is `nil`.
